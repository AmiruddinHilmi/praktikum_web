## Tujuan Praktikum
Membuat aplikasi web CRUD (Create, Read, Update, Delete) untuk mengelola data inventaris alat elektromedis menggunakan PHP Native dan MySQL.

## Teknologi yang Digunakan
- PHP Native
- MySQL
- HTML
- CSS
- XAMPP
- Visual Studio Code

## Fitur Aplikasi
1. Create: Menambahkan data alat elektromedis.
2. Read: Menampilkan data alat elektromedis.
3. Update: Mengubah data alat elektromedis.
4. Delete: Menghapus data alat elektromedis.

## Struktur Database
Nama database: db_alat_elektromedis

Nama tabel: alat_elektromedis

Kolom:
- id
- nama_alat
- tahun
- merek
- lokasi

## Cara Menjalankan Aplikasi
1. Install dan jalankan XAMPP.
2. Aktifkan Apache dan MySQL.
3. Buat database db_alat_elektromedis melalui phpMyAdmin.
4. Buat tabel alat_elektromedis.
5. Letakkan folder project di dalam htdocs.
6. Buka browser dan akses:

http://localhost/praktikum_web/Modul%205/index.php
